# xui/ — отдельный сервер с 3x-ui (вторая панель)

Для схемы с двумя панелями сразу (`PANELS=marzban,xui` в `.env` бота, см.
`bot/panels/multi.py`): Marzban с нодами — главная, рядом независимый сервер
со своей 3x-ui. Бот выдаёт/продлевает клиента в обеих, клиент получает две
ссылки-подписки.

- `bootstrap.sh` — подготовка свежего VPS под 3x-ui: SSH на 2222 (с учётом
  socket-активации Ubuntu 24.04), UFW в безопасном порядке, опционально порт
  только для диапазонов Cloudflare, установка 3x-ui, BBR. Перенесён из
  рабочих заметок как есть, пока интерактивный — бот его ещё не вызывает.
- `CLOUDFLARE.md` — runbook по VLESS+WS+TLS за Cloudflare на 3x-ui
  (externalProxy, origin-сертификат, «чистый» CF-IP, диагностика) — второй
  транспорт на случай, если REALITY напрямую начнут душить.

После установки панели: в 3x-ui создать API-токен, в `.env` бота заполнить
блок 3X-UI (`XUI_BASE_URL`, `XUI_API_TOKEN`) и `PANELS=marzban,xui`,
перезапустить бота (`./deploy.sh`).

Что ещё не сделано для 3x-ui (есть только у Marzban): REALITY-меню, карточка
сервера, проверка туннеля, апгрейд xray, WARP — в работе.
